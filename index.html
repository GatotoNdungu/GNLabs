Recent work, with what changed.

A few problems where modelling, control and software came together to move a real number.

Diagnostics retrofit

Telemetry for a legacy bottling line

Sensor telemetry and a diagnostics layer added to a line that had no spare capacity for downtime, without touching the existing control system underneath.

Fault diagnosis time dropped from roughly four hours to under twenty minutes.
Read the case study
Digital twin

Process model for a batch mixing line

A dynamic model of the mixing process, used to test control assumptions and pre-tune the loops before anything was deployed on site.

On-site commissioning time fell from about three weeks to eight days.
Read the case study
Hardware-in-the-loop

HIL rig for a conveyor safety interlock

A hardware-in-the-loop rig used to run fault conditions against the interlock logic before it ever touched the live conveyor.

Surfaced two sequencing faults that would otherwise have caused an unplanned stop.
